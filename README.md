# DFA Minimizer Visualizer

A web-based tool that visualizes DFA minimization, built as a semester project for Theory of Automata & Formal Languages.

## How to Run

### Option A — VS Code Live Server (Recommended)
1. Open the project folder in VS Code
2. Install the Live Server extension (by Ritwick Dey) from the Extensions tab
3. Right-click `index.html`
4. Opens at `http://127.0.0.1:5500`

> **Note:** Do not open `index.html` directly via double-click (`file://` protocol). External scripts like vis.js may be blocked by the browser.
